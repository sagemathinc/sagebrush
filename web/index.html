      + Text adds a Markdown cell (headings, lists, tables, links, $math$): Shift+Enter shows it, double-click edits it. Shift+Enter runs a cell and moves on; Ctrl/Cmd+Enter runs it in place; Alt+↑/↓ moves it; the ⋯ menu inserts, moves and deletes cells. In a cell, Tab after a name completes it (e.Tab lists what e can do; ↑/↓ and Enter choose), and otherwise indents: press Esc first to Tab out of the cell. Variables persist between cells and are shared with the Console. In Sage mode ^ is a power (^^ is xor), 2/3 is an exact rational and factor, is_prime, next_prime, divisors, euler_phi, crt … are built in. numpy (validated against NumPy itself: same printed output, same seeded random numbers), matplotlib.pyplot, Sage-style plot, @interact and animate are built in. The language is CPython 3.14's own grammar (syntax errors match CPython), with big integers, fractions, complex/cmath, re, json, collections, functools, generators, async, classes and metaclasses. Pure-Python packages such as mpmath pass their own test suites. In Sage mode ModularSymbols, CuspForms, Newforms, DirichletGroup, EllipticCurve and polynomial factoring over ZZ and QQ (R.<x> = ZZ[]) run on Sagebrush's Rust engines, and so does symbolic calculus: diff, integrate, limit, solve, taylor, desolve (Examples > Calculus), with plot3d and contour, vector-field and slope-field plots. In Magma mode, Magma programs are translated to Python in this page and print what Magma prints. Notebooks (with their output) and files are saved in this browser as you work: File opens, downloads and uploads .ipynb, and Files lists the files Python's open() sees (drop files on the page to add them). Your code runs in a Web Worker on this page; nothing is sent anywhere.

      Command line: curl -fsSL https://get.sagebrush.space/install.sh | sh or npx sagebrush. Source: github.com/sagemathinc/sagebrush · a project of SageMath, Inc.
