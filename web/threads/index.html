Multithreaded linear algebra in a browser tab

A dense matrix product C = A·B (double precision, column-major), computed by Sagebrush's Rust kernel compiled to WebAssembly, first on one thread and then on several threads of this tab. A correctness check runs first; timings are shown only if it passes.

Press Run.

This browser

Preview of the numerics core (design note r4.2, milestone M0). Every thread count uses the same seeded matrices and the same kernel; each thread computes its own block of columns of C, so every entry is summed in the same order and the result is bit-identical for any thread count.
