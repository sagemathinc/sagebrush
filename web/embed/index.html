The notebook as a component

This page is a notebook in a few lines: Sagebrush's notebook component (sagebrush-notebook.js, MIT or Apache-2.0) with its in-browser kernel, keeping its document in memory. A page chooses the kernel (what runs code) and the store (where the document lives, and how changes made elsewhere arrive). See web/notebook/README.md, or the full notebook.

import { createNotebook, WorkerKernel, MemoryStore } from "/sagebrush-notebook.js";

const kernel = new WorkerKernel({ createWorker: () => new Worker("/sagebrush-worker.js", { type: "module" }) });
kernel.start();
const nb = createNotebook(document.querySelector("#nb"), { kernel, mode: "sage", assetBase: "/" });
