Sagebrush · Python in your browser

Python 3.14 compiled to JavaScript — runs entirely on your machine. No server, no WebAssembly, ~0.8 MB.

Shift+Enter runs a cell and moves on; Ctrl/Cmd+Enter runs it in place. Variables persist between cells. The language is CPython 3.14's own grammar (syntax errors match CPython), with big integers, fractions, complex/cmath, re, json, collections, functools, generators, async, classes and metaclasses. Pure-Python packages such as mpmath pass their own test suites. Your code runs in a Web Worker on this page; nothing is sent anywhere.

Command line: curl -fsSL https://get.sagebrush.space/install.sh | sh or npx sagebrush. Source: github.com/sagemathinc/sagebrush · a project of SageMath, Inc.
