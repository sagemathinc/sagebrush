      Notebook tips
      • The keys are Jupyter's: Shift+Enter runs a cell and moves on, Ctrl/Cmd+Enter runs it in place; Esc is command mode (A/B insert, DD deletes, M/Y switch to Markdown or code, H lists them all); Ctrl+; splits a cell. Drag a cell by its prompt to move it; hover between cells to add one.
      • + Text adds a Markdown cell (headings, lists, tables, links, $math$): Shift+Enter shows it, double-click edits it.
      • Tab after a name completes it (e.Tab lists what e can do); otherwise it indents: press Esc first to Tab out of the cell. File → Print saves the notebook, outputs and all, as a PDF. Variables persist between cells and are shared with the Console.
      • Sage mode: ^ is a power (^^ is xor), 2/3 is an exact rational; factor, is_prime, ModularSymbols, EllipticCurve, polynomial rings, Gröbner bases and symbolic calculus (diff, integrate, solve, desolve) run on Sagebrush's Rust engines.
      • Magma mode: Magma programs are translated to Python in this page and print what Magma prints.
      • Python: CPython 3.14's own grammar, with numpy (checked against NumPy itself), matplotlib.pyplot, Sage-style plot, @interact and animate; pure-Python packages such as mpmath pass their own test suites.
      • Notebooks and files are saved in this browser as you work: File opens, downloads and uploads .ipynb; Files lists what Python's open() sees. Your code runs in a Web Worker on this page; nothing is sent anywhere.
