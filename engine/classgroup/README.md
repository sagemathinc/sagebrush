# sagebrush-classgroup

Class groups of imaginary quadratic fields in pure Rust, MIT OR Apache-2.0.

This is a clean-room implementation from the published algorithms: Jacobson's
self-initialising sieve for relations, Hafner–McCurley style linear algebra,
the Grenié–Molteni bound for generators and Bach's averaged Euler products.
PARI/GP is used only as an oracle and a benchmark, and its documentation was
read. No PARI source was read or ported.

## Status

- Fundamental discriminants D < 0 with |D| < 2^200. The sieve's values must
  fit in i128; D itself is a big integer.
- The result is `h` and the invariants `cyc`, in the same order as PARI's
  `quadclassunit(D).cyc`.
- The result assumes GRH, like PARI's default.
- Real quadratic fields and general number fields are next.

```
cargo run --release -p sagebrush-classgroup --example qcl -- -100000000000000000000000000319
```

## How it works

1. **Generators.** Under GRH the class group is generated by the prime ideals
   of norm ≤ c·log²|D|, with c = 15/4 (Grenié–Molteni; Bach's bound is
   c = 6). The factor base is the split and ramified primes up to that bound.
2. **Relations** (`relations.rs`).
   - For each sieve polynomial `(a x + b)² − D = 4a·Q(x)`, `a` is a product
     of factor-base primes.
   - Only primes up to a tenth of the bound are sieved, with u8 logarithms
     and divisibility tests by multiplying with p⁻¹ mod 2^64.
   - A larger factor-base prime enters a relation as the prime cofactor of a
     candidate. Cofactors beyond the bound are large primes, combined in
     pairs.
   - Every factor-base prime must occur in relations. The first prime of each
     `a` is the least covered one, and its partners are sieved primes. If the
     partners were rare primes, they would satisfy a parity relation and the
     lattice would have index 2^k.
3. **Structured Gaussian elimination** (`linalg.rs`) on ±1 pivots, large
   primes first. It leaves a dense core. If the core lacks rank, the
   pivot-free columns are made the first primes of the next few polynomials.
4. **A multiple of the determinant.** Take the gcd of the determinants of two
   or three independent square subsets of the core. The determinants are
   computed by CRT over word-size primes, with lazily reduced elimination.
5. **Hermite normal form modulo that multiple**, in Barrett arithmetic: u64
   below 2^62, and u128 with 256-bit products below 2^126 (h > 2^62 from
   about 10^38). It
   stops as soon as the determinant drops below √2·ĥ. Here ĥ is the analytic
   class number formula with L(1, χ) from Bach's weighted average of
   truncated Euler products.
6. **Smith normal form**, on the few generators whose HNF diagonal is > 1 after
   the others are substituted away.
7. **Small |D| (< 10^5)** is computed exactly by growing the subgroup
   generated by the prime forms, as in Shanks.

The √2 acceptance test is where rigor still needs work. Bach proved explicit
error bounds for his averaged product, and the code does not check them yet.
Measured against 400 known class numbers up to 10^35, the estimate with
x = 256 is within 4.2%, and the code uses a much larger x (0.3% or better).

## Timing against PARI 2.17.4

One core of an AMD EPYC 7B13. D = −p for primes p ≡ 3 (mod 4) above 10^k.
PARI is `quadclassunit(D)` in a running gp. Ours is `class_group(D)` with the
small-prime table already built (gp likewise starts with its prime table).
Times are in ms:
- up to 10^23: the mean over 50 discriminants;
- from 10^25: the median of 3.
