How to connect your agent to Sagebrush

Choose what you want to do.

⌨️Use Claude Code on your computer with sagebrush.spaceType in Claude Code; what it makes appears in your notebook.›

Add Sagebrush to Claude Code once. Then ask Claude to connect: it gives you a link, you allow it on the page, and the notebooks it makes open there.

claude mcp add --scope user sagebrush -- uvx sagebrush-mcp@latest

Then start claude and type: Connect to my Sagebrush workspace.

Details
  • Needs uv (on a Mac: brew install uv) and Chrome or Firefox. Safari can't reach a program on your computer.
  • @latest: each time Claude Code starts it, uv checks for a newer sagebrush-mcp and runs the newest.
  • Added before 0.10.2? Run once: claude mcp remove sagebrush, then claude mcp add --scope user sagebrush -- uvx sagebrush-mcp@latest.
  • The first time, the browser asks whether sagebrush.space may reach apps on this computer: click Allow.
  • You choose what Claude may do in your workspace, which folders and whether it may run code, and you can revoke it at any time.
  • Other agents that load MCP servers take { "mcpServers": { "sagebrush": { "command": "uvx", "args": ["sagebrush-mcp@latest"] } } }. We haven't tried it with Codex yet.
  • It works only if your Claude Code can load MCP servers.
💬Chat with Claude inside sagebrush.spaceThe chat in your browser, Claude running on your computer.›

A small program on your computer runs Claude with your own Claude login, and you chat with it on the Agents page. It works only in the folders of your workspace that you allow.

npx -y https://agents.sagebrush.cloud/agents/sagebrush-agent-0.8.2.tgz

It prints a link: open it, click Connect, and choose the folders.

Details
  • Needs sagebrush-agent 0.8.2 (the download above), Node 20 or later, and Claude Code logged in once with your Claude account. It doesn't use your Claude Code settings, so it works even if your Claude Code is sandboxed.
  • The sha256 of that file is 7b4ab39279a38620d4957fd8feff5e6787c5c8318a44f13a0ff13855726894f3.
  • Open the link in Chrome or Firefox; the browser asks once whether this site may reach apps on this computer: click Allow.
  • Claude has no shell and none of your computer's files: only the workspace folders you allowed. Your conversation goes to Anthropic.
  • Codex: not here, only on a connected computer.

On dev.sagebrush.space, the testing site:

SAGEBRUSH_AGENT_PAGE=https://dev.sagebrush.space/agents/ npx -y https://agents.sagebrush.cloud/agents/sagebrush-agent-0.8.2.tgz --origin https://dev.sagebrush.space

To run a notebook's code on your own computer instead: Connect a computer. Everything in full, for agents: connect.md.
