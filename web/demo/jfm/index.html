Journal of Fluid Mechanics · JFM Notebooks · Sagebrush

Interactive JFM figures that run entirely in the reader's browser

These are the vortex structures from a published JFM Notebook. The notebook itself runs here unmodified: k3d, scipy.io.loadmat and numpy. It runs on Sagebrush, a Python and Sage environment compiled to WebAssembly. Nothing is computed on a server. The page loads the published data, builds a mesh of half a million triangles, and you can turn it, zoom into it, and fly through it.

Moving around

  • Turn: drag. A flick keeps it spinning.
  • Pan: right-drag or shift-drag, or drag with two fingers.
  • Zoom toward the cursor: scroll, or pinch.
  • Examine a detail: double-click a vortex to glide in and orbit it. Double-click empty space to go home.
  • Fly through the flow: press F or the Fly button. Click to look around with the mouse, and press Esc to release it.
  • W A S D move, Space/Q rise and sink, Shift is faster, and the wheel sets the speed. A gamepad works too.
  • Turntable: T. Full screen: the toolbar at the bottom left.

Why this matters for publishing

  • The reader's own device does the work. No kernel and no server process is started for each reader, so a figure costs the publisher a static file and nothing more. It loads quickly anywhere, and a downloaded 3D view works offline.
  • The published notebook is the figure. “Run the notebook” opens the article's own .ipynb with its data and executes it in the page. In a few seconds the reader can change the color range, the colormap or the threshold and rerun it.
  • Archival and open. The 3D view is one self-contained HTML file with the data inside. It has a static image and a text description for readers and tools that do not run scripts. Sagebrush is open source (MIT or Apache-2.0).
  • It scales to a whole collection. The same runtime can serve every notebook in the series. We plan to run all of them.
The notebooks and data are as published with the article (the D notebook mirrors the U one, with its own data file and color range). Built with Sagebrush by SageMath, Inc., the makers of CoCalc. Try other mathematics on the Sagebrush notebook.
