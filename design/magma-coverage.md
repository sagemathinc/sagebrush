# Magma coverage map

Which of Magma's intrinsics work in Sagebrush's Magma front end (`src/magma.ts`, `lib/_magma.py`),
measured by running the Handbook's examples under both systems. Generated by
`scripts/magma-coverage.py` from a corpus kept outside the repository; do not edit by hand.

- Magma: 2.18-5 (the oracle), and the intrinsic list of its Handbook.
- Sagebrush: commit `5c95913e4442` (magma-session).
- Measured: 2026-10-14. Each example is one program read on stdin (a session) by both systems,
  split into cells at the Handbook's outputs; Magma runs it twice to find unstable output.

Status of an intrinsic in a chapter, from the calls to it in that chapter's examples. Only cells
before an example's first mismatch count, and a status covers only the calls the examples make, not
every signature:

- **works**: Sagebrush binds it and every such cell matches Magma byte for byte;
- **partial**: some of those cells match and some don't; **differs**: none match;
- **untested**: the name is bound (possibly only for other types), but no example in the chapter
  reaches a call to it;
- **missing**: not bound in Sagebrush's Magma runtime.

The evidence column counts the cells and, for failures, why they failed (the first error).
