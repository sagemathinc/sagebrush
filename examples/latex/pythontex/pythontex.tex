\section*{PythonTeX}

\emph{In this preview:} press \textbf{Run} to run the Python code (\verb|\py|, \texttt{pycode} and \texttt{pyblock}).
Its results then appear as a full PythonTeX run (latex, then pythontex, then latex again) puts them in: \verb|\py|'s
and \texttt{pycode}'s where the code stands, \texttt{pyblock}'s at \verb|\printpythontex|. Other PythonTeX commands
are shown but not run.

\begin{pycode}
from math import comb, factorial
rows = [[comb(n, k) for k in range(n + 1)] for n in range(6)]
\end{pycode}

Ten factorial is \py{factorial(10)}, and $\binom{10}{3}$ is \py{comb(10, 3)}.

The sixth row of Pascal's triangle: \py{rows[5]}.

\begin{pyverbatim}
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
\end{pyverbatim}
