# @sagebrush/cremona-small

John Cremona's elliptic curves of conductor below 1000 (ecdata, under the
Artistic License 2.0; see NOTICE.md at the repository's root): label,
minimal a-invariants, rank and torsion order, for Sage mode's curves by
their Cremona labels, such as `EllipticCurve('11a1')` (lib/_sage_modular.py).
A package (scripts/packages.mjs), imported on first use.
